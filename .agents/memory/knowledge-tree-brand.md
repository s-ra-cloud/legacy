---
name: Knowledge Tree brand consistency
description: User requirement to keep Knowledge Tree visually consistent with the rest of Legacy.
---

The Knowledge Tree module's visual design should be the same as the rest of the site.

**Why:** The user explicitly requested this after the module was introduced with a separate visual identity.

**How to apply:** When changing Knowledge Tree presentation, use Legacy's shared visual language rather than introducing an independent module brand. Preserve its existing data and functionality.
